# Screenshot notes

These PNGs were captured from the actual LeanPlate HTML pages in Chrome on Windows on November 9, 2026, using Playwright with network access disabled. They are browser screenshots, not generated UI concepts.

| File | Screen | Viewport |
| --- | --- | --- |
| `landing-desktop.png` | Welcome page | 1536 × 1024 |
| `food-library.png` | Food search and nutrition table | 1536 × 1024 |
| `meal-editor.png` | Creating a meal with ingredient amounts and serving totals | 1536 × 1024 |
| `saved-meals.png` | Saved example meal | 1536 × 1024 |
| `landing-mobile.png` | Welcome page at phone width | 390 × 844 |

The example “Salmon & quinoa bowl” contains 150 g cooked salmon, 125 g cooked quinoa, and 50 g avocado, divided into two servings. It was created only in a temporary, isolated browser context. No existing user's meals were read or modified, and the project contains no preloaded meal data.

The capture run observed no JavaScript errors or network requests. Food photography visible inside the screenshots is a bundled generated illustration; see the project's `SOURCES.md` for provenance.
